# 🎓 Pygame GUI Tutorial Series

This repository contains a **20‑lesson progression** designed to teach the fundamentals and intermediate techniques of building graphical user interfaces using `pygame_gui`.
Each file is a standalone example focusing on one core concept, allowing you to learn step‑by‑step without being overwhelmed.

---

## 🧭 Series Overview

Across these 20 lessons, you’ll learn how to:

- Build reusable GUI architectures
- Work with windows, panels, tabs, dialogs, and overlays
- Create interactive controls like sliders, dropdowns, checkboxes, and progress bars
- Implement HUDs, pause menus, inventory systems, and consoles
- Mix raw Pygame drawing with `pygame_gui` widgets
- Animate UI elements
- Build drag‑and‑drop interfaces
- Simulate file browsers
- Manage shared UI state
- Construct multi‑page mini‑applications

By Lesson 20, you’ll have a fully functional **Control Center App** demonstrating nearly every major feature of `pygame_gui`, including a custom tab system compatible with `pygame_gui 0.6.10`.
